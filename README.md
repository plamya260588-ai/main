# Personal AI Workspace

Репозиторий для хранения и развития персональных skills, инструкций для агентов и рабочей документации.

## Структура

- `skills/` — переиспользуемые skills: инструкции, которые расширяют рабочие сценарии агента.
- `agents/` — общие правила и конфигурации для специализированных агентов.
- `docs/` — документация, заметки по решениям и руководства по использованию.

## Первые skills

- `skills/universal-assistant/` — универсальный помощник для разбора сложных задач и подготовки практического результата.
- `skills/book-to-framework/` — превращает содержание книги или стандарта в применимые фреймворки и рабочие процессы.

Каждый skill хранится в отдельной папке. Его главные инструкции находятся в файле `SKILL.md`.
