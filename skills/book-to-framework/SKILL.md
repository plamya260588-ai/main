# Book to Framework

## Назначение

Используй этот skill, когда нужно не просто пересказать источник, а извлечь из него рабочую систему, пригодную для реального применения.

## Результат

Подготовь структурированный набор:

1. Ключевые идеи и допущения источника.
2. Фреймворки — модели, которые помогают принимать решения.
3. Рабочие процессы — последовательности действий для типовых ситуаций.
4. Практики и техники — конкретные способы выполнения шагов.
5. Чек-листы — короткие списки для применения и проверки качества.

## Правила преобразования

1. Опирайся на содержание источника; отделяй его идеи от собственных дополнений.
2. Не добавляй абстракции, которые нельзя применить в действии.
3. Для каждого элемента указывай: когда применять, какие входные данные нужны, шаги и ожидаемый результат.
4. Выделяй ограничения, риски и случаи, когда подход не подходит.

## Что развить дальше

- шаблон итогового документа;
- критерии отбора идей из источника;
- примеры преобразования для книг, стандартов и транскриптов.
